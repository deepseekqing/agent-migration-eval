# Σ（记忆材料）规格 v2

Reload 条件给新会话的材料包。C1 实测使用的四种材料（按顺序放入上下文）：

1. **状态页**（hot state）：当前在做什么、待办、约束（≤4KB，只放不可从文件即时查到且会改决策的内容）。
2. **本能清单**：不可压层的硬规矩（红线、安全边界、审批纪律）。
3. **判断库结论列**：判断 id + 结论句（前 60 行即可；边界/来源在判断卡里，按需读）。
4. **交接文档**（handoff）：重启/换会话后的第一动作、状态、指针。

## 要求

- 材料必须**自足**：新会话只靠这些就能回答「在做什么、下一步、什么不能破」。
- 材料必须**可核**：每条规则/数字带文件指针，便于审计。
- 材料**不含**：未脱敏的个人隐私、密钥、会变化的临时状态。

## 给第三方复现的最小自建版

- 状态页：项目当前状态（≤4KB，含待办与硬约束）。
- 本能/硬规则：5–10 条不可破的约束。
- 判断/原则库：20–60 条「在什么场景选 A 不选 B」的结论（带反例边界）。
- 交接文档：一页，写清下一步与指针。
